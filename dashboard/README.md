# Automation Control Dashboard

Локальный dashboard для наблюдения за оркестратором и агентными процессами.

Запуск всего контура из корня проекта:

```powershell
docker compose up -d --build
```

Адрес: `http://127.0.0.1:4173`

Dashboard обновляет данные каждые 10 секунд и показывает:

- форму запуска аналитического запроса с результатом в Markdown;
- форму запуска `bug-finding` для точной ревизии с независимо проверяемыми reproducer-тестами;
- состояние оркестратора, песочницы Docker, обработчика и поставщика модели;
- готовность Plane, SWIRL и маршрута знаний BookStack;
- активные и завершённые workflow;
- текущие шаги, причины технических ошибок и ожидание проверки;
- одобрение, возврат на доработку, отмену и ручной повтор процесса;
- доступные сценарии с явным этапом (аналитика, разработка, тестирование и другие), подключаемые
  средства и образы Harness.

Все данные читаются из локального Orchestrator API. Dashboard не сохраняет
ключи и не передаёт данные во внешнее хранилище.
