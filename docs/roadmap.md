## Архитектурные правила

- Сценарий является графом шагов с переходами по `SUCCESS` и `FAILURE`; граф может содержать циклы.
- Поддерживаются шаги `command`, `agent` и `review`.
- Бизнес-результат шага отделён от технического состояния выполнения.
- Технический `ERROR` обрабатывается повторной попыткой и не является `FAILURE`.
- Каждый запуск агента выполняется в отдельной Docker-песочнице.
- Сценарий задаёт необходимые расширения, а оркестратор выбирает готовый образ или собирает и кеширует новый.
- Агент записывает результат в `output/`, после чего оркестратор проверяет и нормализует его.
- Оркестратор формирует для следующего агента только относящийся к задаче контекст.
- Повторная доставка события, повтор шага и повтор внешней операции не должны создавать дубликаты.
- Gitea используется для создания и проверки запросов на слияние; финальное принятие изменений выполняет пользователь.
- SWIRL является единой точкой федеративного поиска по корпоративным источникам.

## Среда разработки

- Jira и Confluence остаются целевыми корпоративными системами.
- В локальной разработке Plane используется как аналог Jira, а BookStack — как аналог Confluence.
- Plane подключается через обработчик внешних событий; BookStack доступен только через SWIRL.
- Внутренние модели, сценарии и договоры интеграций не должны зависеть от особенностей Plane или BookStack.

### Режимы по объёму памяти

- Основной локальный режим — малоресурсный: оркестратор, обработчик, панель и лёгкий SWIRL-совместимый поиск по локальным JSON-документам.
- Gitea запускается по требованию отдельным профилем. Для сценария с запросом на слияние её можно добавить к малоресурсному режиму.
- Полный SWIRL и Redis запускаются только для отдельной проверки интеграции и не должны постоянно работать на машине с малым объёмом памяти.
- Лёгкий поиск является только средством разработки: он сохраняет программный договор SWIRL, но не заменяет его федеративный поиск в целевой среде.
- Команда основного режима: `./scripts/dev/start-low-memory.ps1`. Ключ `-WithGitea` добавляет Gitea, ключ `-CoreOnly` отключает даже лёгкий поиск.
