# План расширений DeepSeek Harness

Источник требований: [полное описание архитектуры](../architecture.md), разделы 9, 13 и 18.

## Назначение

Расширение — установленная в образ дополнительная возможность агента. В сценарии указываются непосредственно названия необходимых расширений. Отдельная модель разрешений или возможностей на уровне сценария не требуется.

В полном плане приведены расширения:

- Git;
- Gitea;
- SWIRL;
- Python.

Подходящий образ должен содержать как минимум все расширения, необходимые конкретному шагу агента. Если готового образа нет, оркестратор собирает и кеширует новый.

## Интеграции

- [Gitea](../plugins/gitea.md) используется агентом для подготовки изменений и запроса на слияние.
- [SWIRL](../plugins/swirl.md) предоставляет агенту единый интерфейс поиска по корпоративным источникам.
