# AI Cron MVP

Локальный прототип AI-задач, выполняемых вручную и по cron-расписанию.

## Запуск тестовой версии

Нужны Node.js 22.13+, Docker Desktop и авторизованный Codex CLI:

```bash
codex login status
npm install
npm run dev:all
```

После запуска доступны:

- интерфейс: `http://127.0.0.1:3000`;
- локальный Codex и Docker runtime: `http://127.0.0.1:3010`;
- mock MCP с Git и Plane: `http://127.0.0.1:3020/mcp`.

Локальный `.env` уже включает режим `LLM_MODE=codex` и модель `gpt-5.6-luna`. В этом режиме отдельный API-ключ не нужен: runtime вызывает установленный Codex CLI, использующий текущий вход через ChatGPT. Этот вариант предназначен только для локальной разработки.

Когда модели нужны вычисления, она запрашивает `execute_bash`. Команда выполняется в одноразовом Docker-контейнере без сети и файлов хоста, с ограничениями CPU, памяти, процессов, размера вывода и времени.

## Mock-источники

Mock MCP реализует два инструмента:

- `git.get_recent_changes` — последние коммиты тестового репозитория;
- `plane.get_recent_issues` — задачи тестового проекта Plane.
