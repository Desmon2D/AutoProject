# План песочницы DeepSeek Harness

Источник требований: [полное описание архитектуры](../00_full_agent_architecture.md), разделы 5.2, 9–12 и 18.

## Запуск

Каждый запуск шага агента выполняется в отдельном изолированном Docker-контейнере.

Песочница содержит:

- DeepSeek Harness;
- необходимые расширения;
- рабочую директорию;
- входной контекст;
- директорию `output/`.

## Результат

Минимальная структура результата:

```text
/output/
    result.json
    artifacts/
```

`result.json` является обязательным машиночитаемым договором между песочницей и оркестратором.

После завершения контейнера оркестратор:

1. считывает содержимое `output/`;
2. проверяет результат;
3. преобразует его в единый результат шага.

Единый результат содержит идентификаторы шага и исполнения, номера логического выполнения и технической попытки, техническое состояние, бизнес-результат, небольшие структурированные данные и ссылки на артефакты.
