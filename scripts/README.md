# Служебные скрипты

- `dev/` — запуск и подготовка локальных сервисов.
- `setup/` — интерактивная настройка провайдеров и локальных секретов.
- `smoke/` — быстрые сквозные и интеграционные проверки.

Скрипты рассчитаны на запуск из корня репозитория через PowerShell 7. Основная
команда локального режима:

```powershell
.\scripts\dev\start-low-memory.ps1
```
